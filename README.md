# Security Engineer Portfolio

Hands-on cloud security and GRC projects: access reviews, risk, policy and audit readiness. Lab work is built and tested in my own account with real results documented. Exercises that use invented data are labeled fictional or synthetic. Limits are stated plainly. No client data, no real account details.

By Isaac Coker. Focus: cloud security, GRC, and controls mapped to NIST 800-53.

## How to read a project folder

Each folder has a README with the goal, method, real results and limits. Lab projects also include a RUNBOOK to repeat the work and cleanup commands so nothing is left running. Anything invented is labeled SYNTHETIC or FICTIONAL.
